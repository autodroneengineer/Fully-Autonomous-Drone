# 🛰️ Fully Autonomous Drone Powered by using PX4 & Raspberry Pi 4

> A next-gen, remoteless drone system with real-time AI-based navigation, obstacle avoidance, voice control, in-flight charging, and autonomous decision-making.  
> Developed by **Abhishek Singh Narwariya**, B.Tech IT, MITS Gwalior.

---

## 🚁 Project Overview

This project demonstrates a completely autonomous drone built without a remote controller, capable of:

- Fully autonomous **takeoff, mid-air pathfinding, and landing**
- Real-time **obstacle detection and avoidance** using ultrasonic, IR, and LiDAR sensors
- **Voice command interface** for controlling flight behaviors
- **Cameraman mode** with face detection and human tracking
- Smart **autonomous delivery system**
- AI-powered **dual battery management** with **in-flight charging using thermoelectric modules (TEGs)**

---

## 🎯 Key Features

| Feature | Description |
|--------|-------------|
| 🚀 **Autonomous Navigation** | Real-time decision-making based on sensor input for movement |
| 👁️ **Face Detection & Human Following** | Computer Vision-based cameraman mode |
| 🔊 **Voice Control** | Offline voice recognition system to command the drone |
| ⚡ **In-Flight Charging System** | Boost converter + TEG modules powered by magnified sunlight |
| 🔋 **Smart Battery Management** | AI-based switching and monitoring between 2 LiPo batteries |
| 🛡️ **Obstacle Avoidance** | 6x HC-SR04 ultrasonic, 1x LiDAR, 1x IR sensor integrated via ROS |
| 🌐 **Remote-Free Operation** | Fully algorithmic control with no manual intervention |

---

## 🔧 Tech Stack

- **Hardware**: Raspberry Pi 4, Pixhawk, HC-SR04 (6), IR Sensor, LiDAR, GPS, 3S 5200mAh LiPo, HZ-20, TGM-127-1.4-2.5, SP1848
- **Software**: PX4, ROS (Robot Operating System), Ubuntu Server 22.04.5, MAVLink, Mission Planner, OpenCV, Python, C++
- **AI/ML**: Object detection, voice command model, battery switching logic
- **Power**: Supercapacitor buffers, solar-heated TEG modules, AI-based charge control
